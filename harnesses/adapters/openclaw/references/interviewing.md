# Interviewing

This document expands the `## Clarifying Questions` section of `SKILL.md`.

## No numerical question cap

There is no fixed maximum number of clarifying questions. Ask only when an answer can change the outcome.

## When to ask

Ask when the answer can change:

- Which products qualify for the brief.
- The ranking materially.
- The budget, currency, or regional availability.
- A contradiction between requirements.
- The safety or suitability of a recommendation.
- The product type when the request leaves it ambiguous.

## When not to ask

Do not ask when:

- The information is already in the brief or in confirmed preferences.
- The user has already said "use your judgment" for the relevant scope.
- The question is a generic intake item unrelated to the current purchase.
- The brief is already sufficient to perform a useful search.
- The answer would only affect an optional cosmetic preference.

## Mid-task changes

The user may revise any answer, add a constraint, or relax a constraint mid-task. Update the brief, restate the changed assumption, and continue. Never ask for a known value again; carry it forward.

## When to stop

Stop asking once the brief is sufficient to search. A useful search is one that can produce source-backed candidates. The search may return unknown or negative results; that is acceptable. Continuing to question after a useful search is possible delays the user without adding evidence.

## Assumptions

When the user skips a question, says "use your judgment," or declines to answer, state the assumption in plain language, label it in the recommendation output, and continue.
